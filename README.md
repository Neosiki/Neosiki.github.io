# 윤영식 AI·AX 포트폴리오

AI·AX 교육, 소상공인 현장 컨설팅, 에이전틱 업무 자동화, 검증 가능한 전자출판, 뉴스룸 Video-First, 데이터·팩트체크 저널리즘 프로젝트를 소개하는 포트폴리오 홈페이지입니다.

## 주요 구성

- 대표 프로젝트 및 상세 자료 연결
- Bookforge 상업도서급 전자출판 파이프라인 사례 연구
- 외부 기관 검토용 선별 프로젝트 36건
- 소개·커리어 페이지: 경력 연표, 전문 영역, 최근 강의, 수상·대외활동
- AI·AX 교육·컨설팅 전문 영역
- Google 자격·수료 8건
- Anthropic Education 자격·수료 21건
- 자격증 이미지 필터 및 확대 보기

## Design Studio P1 다음 단계

P0에서 작업 상태·진행률·취소·재시도, 증분 렌더링·stale 관리, 검수 수정 제안·승인 적용을 구현했다면, P1은 실제 팀 운영과 반복 제작의 효율을 높이는 단계입니다. 우선순위는 다음과 같습니다.

| 우선순위 | 주요 기능 | 기대 효과 |
|---|---|---|
| P1·01 | 작업 큐와 동시 실행 제어 | 여러 산출물의 우선순위·대기열·동시 실행 수를 관리하고 자원 충돌을 줄임 |
| P1·02 | 팀 협업·권한·감사 로그 | 검토자·승인자·변경 이력을 남겨 책임 있는 협업과 되돌리기를 지원 |
| P1·03 | 시각 회귀·품질 대시보드 | 렌더 결과 비교, QA 추이, 실패 원인과 개선 우선순위를 한 화면에서 확인 |
| P1·04 | 템플릿·플러그인 확장 구조 | 조직별 템플릿과 HTML·문서·영상 출력 모듈을 재사용 |
| P1·05 | 원격 산출물 저장·보존 정책 | 결과물 버전, 보존 기간, 복구 지점을 운영 기준에 맞게 관리 |

## 홈페이지 방문자 분석 위젯

홈페이지에는 개인정보를 과도하게 수집하지 않는 선택형 GoatCounter 위젯을 추가했습니다. 현재 정적 GitHub Pages에는 사이트 코드가 설정되지 않아 `연결 대기`로 표시되며, 임의의 조회수를 표시하지 않습니다. GoatCounter 사이트를 만든 뒤 `index.html`의 `ANALYTICS_CONFIG.goatCounterCode`에 발급된 사이트 코드만 입력하면 페이지 조회수와 전체 사이트 조회수가 표시됩니다.

```js
const ANALYTICS_CONFIG = { goatCounterCode: '발급받은-사이트-코드' };
```

사이트 코드를 비워 두면 추적 스크립트와 조회 요청을 전혀 실행하지 않습니다. 코드가 설정된 경우에만 GoatCounter의 페이지뷰 수집 스크립트와 공개 카운터 JSON을 사용하며, 위젯에는 요약 수치만 표시합니다. GoatCounter의 사이트 설정과 방문자 카운터 공개 설정은 서비스 대시보드에서 별도로 확인해야 합니다.
